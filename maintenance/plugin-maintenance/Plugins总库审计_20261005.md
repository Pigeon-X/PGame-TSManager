## 四、维护规则（以后照这个来）

1. **插件本体** → 放进 `Plugins\`（总库）。换版本只替换同名 dll。
2. **插件的依赖库**（不含 TShockAPI/TerrariaPlugin 引用的，如 linq2db / Mono.Cecil / MonoMod / SQLitePCLRaw）
   → 放进 `bin\`。（判断工具：`maintenance\tools\Sort-PluginDependencies.ps1`）
3. 同步：`PGame-TSManager.exe --syncplugins` 把总库镜像到共享 `ServerPlugins`。
4. 哪个服要**停用某个插件**：在该服 `tshock\` 下找插件的配置文件（多数有 `启用` 开关），
   **不要**靠删 ServerPlugins 里的 dll（那是三服共用的）。
