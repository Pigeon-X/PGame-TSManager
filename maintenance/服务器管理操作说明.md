# PGame-TSManager 服务器管理操作说明

## 日常启动

1. 双击 `PGame-TSManager.exe`，只会显示管理器窗口。
2. 顶部菜单栏集中放置「服务器 / 管理 / 工具」功能。
3. 在下拉框选择服务器，查看运行状态和在线人数；右侧按钮分别是「启动本服」「停止本服」「全部启动」「全部停止」。
4. 日常开服使用「全部启动」，管理器会等待上一台端口就绪后再启动下一台。
5. 底部只保留一行指令输入和发送按钮；点击窗口右上角关闭时，按提示选择缩小到托盘或退出。

## 发管理员指令

在底部输入框输入中文或英文指令，回车发送给当前服务器；按钮「全部发送」会发送给所有运行中的服务器。
指令会自动补 `/`，例如输入 `help` 等同于 `/help`。`/help` 由 TShock 原始指令处理，管理器不覆盖。
HotReload 插件命令可在输入框执行 `/hr` 查看状态、`/hr help` 查看帮助；该命令需要 `hotreload.admin` 权限。管理器不提供热重载快捷按钮，避免误操作。

## 插件管理

在菜单栏「管理 → 插件开关…」选择本服从总插件库加载的插件，保存后可选择重启本服。
插件列表会显示 DLL 文件名和简短中文用途；没有内置说明的插件显示“自定义或专用插件”。

「管理」菜单还包含「新建服务器」「刷新服务器列表」；「工具」菜单包含「保存世界」。

- 插件本体放根目录 `Plugins`。
- 插件依赖放根目录 `bin`。
- 每服加载清单只写在 `1.PigeonServers\<服务器>\config.json`。
- 修改插件后必须重启对应服务器，不能在玩家在线时直接覆盖正在加载的 DLL。

## 服务器设置

在菜单栏「管理 → 服务器设置…」打开当前服务器的配置窗口。

- 「TShock 配置」分页编辑 `tshock\config.json`。
- 「超级管理员聊天颜色(RGB)」使用调色板 UI，可选择预设颜色或直接修改 R / G / B。
- 「SSC 配置」分页编辑 `tshock\sscconfig.json`，界面将常见 SSC 字段显示为中文，底层仍保持英文键不变。
- `StartingInventory` 使用专用物品 UI：物品名可搜索中文名称，支持数量、前缀、收藏、添加和删除；物品数据仍只保存 `netID / stack / prefix / favorited`。
- 当前 SSC 原生格式没有“后缀”字段，界面明确标注不支持后缀，避免写坏配置。
- 每页支持按配置名、路径或当前值搜索；普通文本、数字、布尔值可直接修改，数组/对象按 JSON 编辑。
- 保存前会自动生成 `.bak` 备份；可选择「保存」或「保存并重启本服」。
- 「保存并重读」会发送 `/reload ssc`，用于 SSC/热重载场景；保存失败会按对应配置文件显示错误。
- 「更多设置」分页预留给后续世界、备份、数据库、REST、插件数据等配置。

## 配置边界

服务器配置位于 `1.PigeonServers\<服务器>\tshock`，世界和数据库属于运行数据。
管理器启动前会备份关键配置；管理器本身不会自动重写 TShock 配置。

TShock 更新使用 `maintenance\tshock-update` 的独立流程，不从管理器界面执行。

## 故障处理

- 服务器异常退出：看门狗默认等待 8 秒自动重启，连续 3 次后停止并上报。
- 「停止本服」「全部停止」会先弹出二次确认，可选择取消；「全部启动」「全部停止」会根据服务器状态自动置灰。
- 启动失败：先看管理器面板和 `Logs`，再运行 `PGame-TSManager.exe --selfcheck`。
- REST 无法发指令：检查该服 `tshock\config.json` 的 REST 端口和令牌字段「用户名 / 用户组」。
- 配置汉化检查：运行 `maintenance\tools\Test-TShockConfig.ps1`。
- TShock 更新失败：使用 `Backups\tshock-update-时间戳` 回滚核心文件，再按顺序启动。
