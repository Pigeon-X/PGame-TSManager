# TShock 更新维护待办

## 当前已经具备

- 正式版来源与 Actions 测试版来源说明。
- 独立更新脚本 `maintenance/tools/Invoke-TShockUpdate.ps1`。
- staging 目录、核心文件同包校验、时间戳备份和预览模式。
- `config.json` 中文映射、REST「用户名 / 用户组」校验。
- SSC 英文冻结和 `/help` 行为冻结规则。
- GitHub Actions 源码包与管理器模板包构建。
- 远程源测试端的 Git 构建、部署、可见重启和三服端口验证流程。

## 仍需完善

1. **官方包自动获取**：当前要求人工从 Releases 或 Actions 下载 ZIP，再交给独立脚本；后续可增加版本选择、下载缓存和 SHA256 校验。
2. **汉化自动应用**：当前保留映射和人工维护边界，尚未把新版 TShock 的字段差异自动生成迁移报告。
3. **多版本回归矩阵**：目前重点验证当前远程三服，尚未自动保存多个 TShock 版本的 `/help`、REST、SSC 和插件启动结果。
4. **完整回滚演练**：已有文件备份和手动恢复说明，尚未在远程定期自动执行一次恢复演练。
5. **插件兼容报告**：尚未自动按插件逐个记录加载成功、异常、缺依赖和耗时。
6. **发布签名**：Actions 产物已有构建结果，尚未加入发布包签名和独立校验文件。
7. **远程部署脚本参数化**：当前远程路径和服务器身份按本项目固定，换服务器时还需要手动调整连接配置。

## 当前执行约束

- TShock 更新不放进 PGame-TSManager UI，不由管理器按钮触发。
- GitHub 是唯一上游；远程服务器只做测试和部署，不作为 Git 仓库。
- 每次修改必须先 Git 提交并构建，再到远程源测试端验证。
- 通过远程验证后才同步桌面镜像和上报测试群。
- 不修改 `/help`，SSC 保持英文；REST 令牌字段固定为「用户名 / 用户组」。
