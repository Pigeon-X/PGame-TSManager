## 二、用例与结果

### Run A｜启动即困难（`强制困难模式=true`）

配置：`自动跟随世界阶段=true`、`强制困难模式=true`、`阻止困难化=false`、`世界阶段=肉前世界`

启动后日志（stdout）：

```
[PigeonRPG.ProgressGuard] 世界阶段自动切换：肉前世界 -> 困难世界
```

✅ **通过** —— 证明：`ForceHardmode` → `OnGamePostInitialize` → 自动切换链路成立。

### Run B｜真·肉前世界 + 运行期翻困难（**最接近真实场景**）

配置：`自动跟随世界阶段=true`、`强制困难模式=false`、`阻止困难化=false`、`世界阶段=肉前世界`，世界 = 直播服真·肉前世界副本

| 步骤 | 期望 | 实测 |
|---|---|---|
| 启动（世界是肉前） | 有效阶段保持"肉前世界"，**不切换** | ✅ 无切换日志（正确，无假阳性） |
| 控制台执行 `/hardmode`（等价肉山后世界翻困难） | ≤10s 内（tick 兜底 600 帧）自动切困难 | ✅ **5 秒内**出现：`世界阶段自动切换：肉前世界 -> 困难世界` |

✅ **通过** —— 证明：
1. **`OnGameUpdate` 低频兜底确实生效**（不依赖 Hook 触发）；
2. **自然困难化路径**（世界标志变 true）能驱动阶段切换，不需要重启或改配置；
3. auto=true 且世界为肉前时**不会误切**。

### 未能覆盖的用例（沙箱限制，非功能缺陷）

| 用例 | 状态 | 原因 |
|---|---|---|
| 困难阶段拦"肉前 Boss"（`已阻止跨阶段 Boss`） | 未触发 | TShock 的 `/spawn` `/spawnboss` `/spawnmob` 都要求**真玩家**（控制台返回"你必须在游戏内使用该指令"）；`/worldevent` 事件在**0 人在线**时不实际生成 NPC，所以 `OnNpcSpawn` 没被调用 |
| 肉前阶段拦"困难事件"（`已阻止困难事件`） | 未触发 | 同上（事件无玩家不落地） |

> 说明：`ShouldBlockBoss` / 困难事件限制 与本次切换共用同一个有效阶段出口（`IsPreHardmodeWorld()` / `IsHardmodeWorld()`），
> 且泰拉(2)/神域(3) 一直以静态阶段正常拦截，属于已验证过的代码路径。**如需 100% 覆盖，需要在有真玩家/客户端的环境里补测。**
