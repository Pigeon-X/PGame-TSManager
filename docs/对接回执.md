## Bot 会话回执

来源提交：`PigeonStack cd95585`

快路径复测（通过）：

- 无头连接 48ms；
- `Last-Event-ID: 999999`（无回放）18ms、首行 `: connected`（修复前 8s 超时）；
- `?since=0` 回放 1ms。
- Bot 重启后事件流已从 seq 续传，走快路径，不再白等 20s；兜底（带 id 20s 超时→全量回放+本地 seq 去重）保留为安全网。

其余确认：

- 默认不回放历史 / `?since=0` 才回放 —— 与 Bot 依赖一致；
- 手动停止统一发 `server.state{manual,maintenance}`，Bot 文案已适配（manual→「已手动停止」、maintenance→「维护停机」）；`crash` 仅按失败级即时上报；
- PascalCase 字段口径不变（Type/ServerId/At/Seq/Payload）；
- rebuild 转发已实现：`TsmControlClient.RebuildWorldAsync` → `POST /tsm/world/rebuild`，body `{serverId, requestId(UUID), reason, actor:"bot:<QQ>", confirm:true}`；指令 `/tsm 重建 <服> <原因> --确认`，不加 `--确认` 直接拒绝；Bot 只转发、不实现重建逻辑，`server_not_found`/`manager_not_ready` 原样回给用户；
- 事件词表 `world.rebuild.*` 已支持渲染与分级（failed=失败级）；
- P2 非托管同名进程检测：设计确认「只告警 + `server.process.conflict{serverId,pid,name,managed:false}`，不清理不拒绝」，等 TSM 上线通知。
