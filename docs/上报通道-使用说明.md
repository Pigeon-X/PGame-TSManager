# 统一上报通道（走 Bot 命令，替代自写脚本）

> 来源：Bot 会话 2026-10-10 提供；TSM 侧实测通过

## 用法

```text
cd C:\Users\Administrator\Desktop\PigeonTR.Bot
.\PigeonTR.Bot.exe report --title "<标题>" [--status 成功|警告|失败] [--source TSM]
                          (--body "<正文>" | --file <文本文件> | 管道输入)   [--dry-run]
```

- 上报群取自 Bot 的 `config.json → 上报群列表`（当前 `1125570228` + `561150136`）；**标题自动包 `【流光统一上报】`**。
- `--dry-run`：只打印 + 写本次日志，**不发群**。
- 文档：远程 `C:\Users\Administrator\Desktop\PigeonTR.Bot\文档\BOT-上报接口.md`

## ⚠ 调用方式（实测补充，很重要）

`PigeonTR.Bot.exe` 是 **GUI 子系统**程序。在 **SSH / 非交互 PowerShell** 里用 `&` 调用：
**不等待、拿不到 stdout**，表现为「无输出 + `$LASTEXITCODE` 为空 + 日志里无上报记录」（静默不生效）。

**可靠写法（TypeScript 之外唯一推荐）**：

```powershell
Start-Process -FilePath .\PigeonTR.Bot.exe -WorkingDirectory <BotDir> -Wait `
  -ArgumentList @('report','--title','...','--source','TSM','--status','成功','--body','...') `
  -RedirectStandardOutput out.txt -RedirectStandardError err.txt
```

（交互式控制台里直接 `&` 是可以的；只有 SSH/脚本场景需要上面这种。）
