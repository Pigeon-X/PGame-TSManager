# 鸽子直播服 → Bot 对接回执

> 对应清单：`docs/直播服-对接清单.md`
> 服务器：`serverId=0` 鸽子直播服
> 时间：2026-10-09

```text
【直播服 → Bot】对接回执

1. 重置发起方：
   直播服/直播服运维自己发起，Bot 不代发。
   直播服可通过 TSM 界面或直连 TSM 控制 API 执行；Bot 的“允许世界重建”继续关闭。

2. 重置前 0 人确认方：
   必须 0 人。由直播服/运维在发起前确认，TSM 状态和在线名单作为依据。
   `/pout reset yes` 自身也会倒计时、踢人和等待 0 人。

3. 世界参数/种子：
   当前按大世界 + 大师 + 普通随机执行：
   autocreate=3 / difficulty=2 / worldevil=random / seed=空 / seed_* 全 0。
   注意：该参数是当前运行状态，不是已证实的崩溃修复硬约束。

4. 是否需要 Bot 额外动作：
   不需要。
   Bot 只做自动事件播报：world.rebuild.started / backup_created / generating / ready|failed。
   timeout 是信息性事件；收到 failed 时由直播服/运维用 `/tsm 服务区` + 服务器日志复核。

5. PVP/小游戏场地处理：
   PVP 使用固定坐标区域：2000,250 → 2100,350。
   世界重置后必须重新检查/重建该场地，不能假设随机生成的新地图自动可用。
   小游戏配置当前 `区域=[]`，没有持久化场地定义；手工搭建的场地需在重置后重新布置或恢复。
   Bot 不处理场地。

6. 稳定标识：
   serverId=0 + 名称“鸽子直播服” + 世界名 `鸽子直播服.wld` 已足够；
   不需要新增额外稳定标识。
   restTokenAlias=`0-rest`。

7. 三个 RPG 模块一致性要求：
   插件保持：ProgressSync / ProgressGuard / ProgressLoot。
   版本与规则语义与主服一致；直播服数据库为独立 `1.pgs`，进度数据是建库时从
   `2.pigeonrpg` 复制的快照，不要求与主服实时共库。
   如果未来要求跨服实时进度一致，必须另开数据库/同步方案，不能由 Bot 代做。

8. 需要 Bot 新增的只读接口：
   不需要。现有清单第四节接口足够。
   PVP/小游戏对局状态如需群内展示，再单独评估只读接口。

9. 进程 owner（TSM 托管）：
   确认。TShock 进程由 TSM 托管，Bot 不启动、不停止、不重启、不参与看门狗。

10. 禁止项（Bot 不碰世界文件/进程/配置）：
    确认。Bot 不碰 Worlds/*.wld、server.properties、TSM 配置和每服 tshock 配置。

其它：
- 直播服重置入口和清表归 FixTools，换图执行归 TSM。
- Bot 本地重建闸保持 false，群里不提供代发重建。
- 旧世界备份为 `鸽子直播服.wld.bak-<时间戳>`。
```
