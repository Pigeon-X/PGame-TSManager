## 六、⚠ 上线时发现的两个坑（必须知道的约定）

### 1. `Servers\Profiles\` 下**不能放备份目录**

TSM 会自动发现 `Profiles\*` 里任何带 `config.json`+端口的目录 → 备份目录会被当成**第二台服**（同端口抢占、日志看不出）。

- 本次现象：`0.鸽子直播服.bak-economyshop-20261009-010413` 被自动发现 → 出现两台"鸽子直播服"，先启动的备份实例抢走 2020/7877。
- 已处理：备份移到 `Backups\profiles\`（保留未删）。
- **约定**：profile 备份一律放 `Backups\`，不要留在 `Servers\Profiles\`。

### 2. 建图 StackOverflow —— **根因未确定（间歇性）**

- 现象：世界生成时退出码 `-1073741571`（STATUS_STACK_OVERFLOW），堆栈 `WorldGen.nextCount ↔ mfwh_nextCount` 无限自递归。
- ⚠ **曾误判**为 `PigeonRPG.ProgressLoot`（基于单次沙箱运行），**已撤回**：复测不可复现；
  且全 20 个插件 DLL 的 IL + 字符串扫描中 **`nextCount`/`countTiles`/`mfwh_` 一处都没有**。
- 目前可确定：`mfwh_*` 是 **OTAPI/ModFramework 生成层**的包装；崩溃**间歇发生**（与随机种子/时序相关）；
  唯一确凿线索是 **PGameAPI 安装 MonoMod RuntimeDetour**（涉及 `ModFramework.ICollection<Terraria.ITile>`、`HouseRegion.HouseCore` 等），待 N 次重复统计定论。
- **当前处置（临时，非已证实修复）**：直播服设为 **大世界 `autocreate=3` + 大师 `difficulty=2` + 普通随机种子**，
  并已真机 rebuild 成功一次（世界 6,886,177 → 11,964,749 B，8400×2400）。
- ✅ **直播服当前可用**（可换图/重建/`/pout reset`）。但注意：
  - 「大图+大师」**不是已证实的修复**，只是当前可用状态；
  - 若再次出现 StackOverflow，请保留日志（stdout+stderr）并通知 TSM；
  - 根因查清前，**变更直播服世界参数前先告知 TSM**。
