## 六、⚠ 上线时发现的两个坑（必须知道的约定）

### 1. `Servers\Profiles\` 下**不能放备份目录**

TSM 会自动发现 `Profiles\*` 里任何带 `config.json`+端口的目录 → 备份目录会被当成**第二台服**（同端口抢占、日志看不出）。

- 本次现象：`0.鸽子直播服.bak-economyshop-20261009-010413` 被自动发现 → 出现两台"鸽子直播服"，先启动的备份实例抢走 2020/7877。
- 已处理：备份移到 `Backups\profiles\`（保留未删）。
- **约定**：profile 备份一律放 `Backups\`，不要留在 `Servers\Profiles\`。

### 2. 该服**首次建图会 StackOverflow**（插件缺陷）

- 现象：世界生成时退出码 `-1073741571`（STATUS_STACK_OVERFLOW），堆栈 `WorldGen.nextCount ↔ mfwh_nextCount` 无限自递归。
- 判别结论：**只留 TShockAPI** 时小图生成完全正常 → 是**某个已加载插件装的 `WorldGen.nextCount` 钩子**，不是 TShock 自身、也不是 TSM。
- 本次处理：用干净环境（仅 TShockAPI）预生成 `鸽子直播服.wld`，再带全插件启动 → 现已 **running**。
- ⚠ **影响**：任何**删图重建**（含 `/pout reset` 换图）都会再次触发该崩溃，直到插件侧修好。
