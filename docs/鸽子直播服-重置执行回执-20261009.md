**根因（两处配置错，都在 `Servers\Profiles\0.鸽子直播服\tshock\TileHelper\config.json`）**：

| 配置项 | 直播服（错误） | 泰拉/神域（正确） | 实际文件位置 |
|---|---|---|---|
| `建筑文件` | `spawn_hub.sec3` | `出生点.sec3` | `出生点.sec3`（38×37） |
| `建筑目录` | `buildings` | `tshock/TileHelper/buildings` | `Core\_runtime\鸽子直播服\tshock\TileHelper\buildings\` |
| `偏移X/Y` | `0 / 0` | `-18 / -18` | — |

- `建筑文件=spawn_hub.sec3` 这个文件全盘都不存在 → 日志 `[TileHelper] 找不到建筑文件: buildings\spawn_hub.sec3`，直接跳过。
- 只改文件名还是不行：`建筑目录` 是**相对进程工作目录**解析的（CWD=`Core\_runtime\<服名>`），
  写 `buildings` 会找 `Core\_runtime\鸽子直播服\buildings\`（空），必须写 `tshock/TileHelper/buildings`。

**修复**：
1. `建筑文件` → `出生点.sec3`（与泰拉/神域同一文件，SHA256 一致 `9B962D55…`）
2. `建筑目录` → `tshock/TileHelper/buildings`
3. `偏移X/偏移Y` → `-18 / -18`（与泰拉/神域一致，让 38×37 建筑以出生点为中心）
4. `state.json` 清空 `WorldSeed`/`AutoBuildDone`，重启触发自动粘贴

**结果**：

```
/th origin → ActualOrigin=(4187,596) 世界=26415154-… 已贴=True
```
世界已 `/save`（11,700,014 → 11,709,060 B，22:49:47）。
回滚点：`Backups\tilehelper-fix-20261009-224808\`（原 config.json / state.json）。
